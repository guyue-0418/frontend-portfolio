# 前端作品集页面

Web 开发技术第三次课 10-08 作业：将前三次课程作品汇总成深色风格的前端作品集页面。

## 项目说明

本页面汇总展示三个前端项目，每个项目包含截图、简介、技术标签以及对应的
GitHub 仓库与 Vercel 在线地址：

| 项目 | 说明 | 课程 |
| --- | --- | --- |
| 注册页 · Northline | 带实时校验的注册表单 | 第一次课 |
| Quiz Game · 答题游戏 | 三界面答题小游戏 | 第二次课（课堂） |
| Recipe Finder · 菜单搜索器 | 调用 TheMealDB 的食谱搜索 | 第二次课（课后） |

## 项目文件

- `index.html`：作品集页面结构
- `style.css`：页面样式（深色主题、响应式布局、动效）
- `script.js`：作品卡滚动进入视口动画
- `images/`：三个作品的 800×800 截图
